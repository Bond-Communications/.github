# Bond-Communications/.github

Organization-wide default files. GitHub applies them to every repository in the organization,
public or private, that doesn't have its own file of the same type.

GitHub requires this repository to be public. Don't put anything confidential here.

## Files

- `.github/pull_request_template.md`: default pull request description. Copied from
  `bond-devcontainer/docs/DEVELOPMENT-PROCESS.md`; change it there first, then copy it here.

Add a repository's own template only when that repository needs a different one.
